## Usage

```tsx
import { BrushChart } from "@/components/charts/brush-chart";
```

```tsx
<BrushChart
  data={dailyRevenue}
  index="date"
  categories={["revenue"]}
  defaultWindow={90}
  className="h-64"
/>
```

## Good to know

- The brush under the chart shows the whole series in miniature. Drag its handles to zoom, or drag the window to pan.
- `defaultWindow` sets how many of the latest rows are visible at first. Without it, the whole series shows.
- The brush takes 40px of the chart's height, so give it a bit more room than a plain chart, e.g. `h-60`.
- `onRangeChange` gets the first and last visible row index, e.g. to load detail for that window.
- Use it for hundreds or thousands of rows. For a few weeks of data, a [Time Range Chart](/charts/interactive/time-range-chart) is simpler.

## Props

Takes all the [common chart props](/docs/chart-components/foundation#common-props), plus:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `chartType` | `"area" \| "line"` | `"area"` | Chart to draw |
| `defaultWindow` | `number` | all rows | Latest rows visible at first |
| `onRangeChange` | `({ startIndex, endIndex }) => void` | — | Called when the brush moves |

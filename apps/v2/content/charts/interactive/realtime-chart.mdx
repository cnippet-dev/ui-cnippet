## Usage

```tsx
import { RealtimeChart } from "@/components/charts/realtime-chart";
```

```tsx
<RealtimeChart
  categories={["rps"]}
  onTick={() => ({ rps: latestFromSocket.current })}
  interval={1000}
  windowSize={60}
  className="h-48"
/>
```

## Good to know

- Every `interval` ms the chart calls `onTick` and appends the values it returns. Read the latest value from a ref your websocket or poller updates.
- `windowSize` points stay on screen; older ones scroll off the left.
- The chart starts empty and begins ticking after it mounts, so the server render never differs from the client.
- Lines never animate: a stream redraws every tick, and tweening each update only adds jitter. This also covers reduced motion.
- The pause button stops the interval (points stop arriving); resume continues from now. Start paused with `defaultPaused`.
- Set `yDomain` (e.g. `[0, 100]`) when small moves shouldn't rescale the axis.
- The live values in the header are plain text for screen readers. They aren't announced on every tick, which would be noisy.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `categories` | `string[]` | — | Series keys returned by `onTick` |
| `onTick` | `() => Record<string, number>` | — | Returns the next value per series |
| `interval` | `number` | `1000` | Milliseconds between points |
| `windowSize` | `number` | `60` | Points kept on screen |
| `config` | `ChartConfig` | built from `categories` | Labels or colours per series |
| `valueFormatter` | `(value: number) => string` | `formatCompact` | Formats values |
| `yDomain` | `[number, number]` | fits the data | Fixed y-axis range |
| `showControls` | `boolean` | `true` | Live indicator, values and pause button |
| `defaultPaused` | `boolean` | `false` | Start paused |
| `yAxisWidth` | `number` | `48` | Width of the y-axis |
| `className` | `string` | — | Sizing classes for the chart |
| `aria-label` | `string` | built from `categories` | Accessible name |

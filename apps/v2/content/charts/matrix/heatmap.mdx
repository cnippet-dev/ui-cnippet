## Usage

```tsx
import { Heatmap } from "@/components/charts/heatmap";
```

```tsx
// data: [{ day: "Mon", hour: "9", sessions: 1180 }, …]
<Heatmap data={data} x="hour" y="day" value="sessions" />
```

## Good to know

- Pass one row per cell. Columns and rows appear in the order they first occur in `data`; set `xLabels` / `yLabels` to fix the order or include columns with no data. Cells with no row are left blank.
- Shading runs from the smallest value (`min`) to the largest (`max`). Set both for a fixed scale, e.g. `min={0} max={1}` for shares.
- `xFormatter` and `yFormatter` return the header content. Return `""` to hide some labels, e.g. show every third hour.
- `showValues` prints each value in its cell and switches cells from squares to short bars.
- Keyboard: the grid is a single tab stop. Arrow keys move between cells (skipping blanks), Home and End jump to the ends of a row. Each cell's tooltip text is also its accessible name, so colour is never the only signal. Change the text with `cellLabel`.
- Wide grids scroll sideways inside their own box when cells would be narrower than `minCellSize`.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `T[]` | — | One row per cell |
| `x` | `keyof T` | — | Column field |
| `y` | `keyof T` | — | Row field |
| `value` | `keyof T` | — | Numeric value field |
| `xLabels` / `yLabels` | `string[]` | order in `data` | Column and row order |
| `xFormatter` / `yFormatter` | `(label: string) => ReactNode` | — | Header content |
| `valueFormatter` | `(value: number) => string` | `formatCompact` | Formats values |
| `cellLabel` | `(row: T) => string` | `"<y>, <x>: <value>"` | Tooltip and accessible name |
| `color` | `string` | `"var(--chart-1)"` | Colour of the highest value |
| `min` / `max` | `number` | data min / max | Ends of the colour scale |
| `showValues` | `boolean` | `false` | Print values in cells |
| `showLegend` | `boolean` | `true` | Show the colour scale |
| `minCellSize` | `number` | `0` | Smallest cell width in px |
| `loading` | `boolean` | `false` | Show a skeleton |
| `emptyState` | `ReactNode` | `<ChartEmpty />` | Shown when there are no values |
| `className` | `string` | — | Extra classes |
| `aria-label` | `string` | — | Accessible name of the grid |

## Usage

```tsx
import { Sankey } from "@/components/charts/sankey";
```

```tsx
const data = [
  { source: "Search", target: "Pricing", value: 4200 },
  { source: "Pricing", target: "Signed up", value: 3100 },
  { source: "Pricing", target: "Left", value: 1100 },
];

<Sankey data={data} className="h-72" />
```

## Good to know

- Pass flows by **name**. The chart creates one node per name, in the order the names first appear, so you don't manage node indexes.
- Flows must not form a cycle (A → B → A). Links with a value of zero or less are skipped.
- Each node gets a chart colour, and links take the colour of the node they leave. Override any node with `config`, keyed by its name, e.g. `config={{ Budget: { color: "var(--muted-foreground)" } }}`.
- Node labels show the name and total flow. Labels sit to the right of a node, except in the last column, where they sit to the left so they stay inside the chart.
- Hover a link or node for its value. A visually hidden list repeats every flow for screen readers.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `{ source, target, value }[]` | — | Flows between named nodes |
| `config` | `ChartConfig` | — | Colours/labels per node name |
| `valueFormatter` | `(value: number) => string` | `formatCompact` | Formats values |
| `showTooltip` | `boolean` | `true` | Show the tooltip |
| `nodeWidth` | `number` | `10` | Width of each node bar in px |
| `nodePadding` | `number` | `24` | Gap between nodes in px |
| `loading` | `boolean` | `false` | Show a skeleton |
| `emptyState` | `ReactNode` | `<ChartEmpty />` | Shown when there are no flows |
| `className` | `string` | — | Sizing, e.g. `"h-72"` |
| `aria-label` | `string` | `"Flow diagram"` | Accessible name |

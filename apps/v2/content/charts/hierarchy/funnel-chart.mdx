## Usage

```tsx
import { FunnelChart } from "@/components/charts/funnel-chart";
```

```tsx
<FunnelChart data={data} index="step" category="users" />
```

## Good to know

- Each bar's width is its value as a share of the **first** step. The percentage next to the value is the same share; the "↓" figure next to a step's name is the share lost since the **previous** step.
- It's built from HTML and CSS, not SVG, so labels wrap and the layout works at any width, including phones. There's no separate mobile layout to configure.
- Steps are an ordered list, and every number is plain text, so screen readers read the funnel without extra work.
- `align="start"` left-aligns the bars, which makes small differences between later steps easier to compare.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `T[]` | — | One row per step, in order |
| `index` | `keyof T` | — | Step name |
| `category` | `keyof T` | — | Number reaching the step |
| `valueFormatter` | `(value: number) => string` | `formatCompact` | Formats values |
| `color` | `string` | `"var(--chart-1)"` | Bar colour |
| `showDropOff` | `boolean` | `true` | Show the % lost between steps |
| `align` | `"center" \| "start"` | `"center"` | Funnel shape or left-aligned bars |
| `emptyState` | `ReactNode` | `<ChartEmpty />` | Shown when `data` is empty |
| `className` | `string` | — | Extra classes for the list |
| `aria-label` | `string` | — | Accessible name |

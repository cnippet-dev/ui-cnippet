## Usage

```tsx
import { ChartCard } from "@/components/charts/chart-card";
```

```tsx
<ChartCard title="Revenue" value="$48.2K" delta={0.124}>
  <ChartContainer config={config} className="h-40 w-full">
    {/* any Recharts chart */}
  </ChartContainer>
</ChartCard>
```

## Anatomy

```tsx
<ChartCard            {/* Card */}
  title               {/* CardTitle */}
  description         {/* CardDescription */}
  actions             {/* CardAction, top right */}
  value delta         {/* headline number + Badge */}
  footer              {/* CardFooter */}
>
  {children}          {/* CardPanel: the chart */}
</ChartCard>
```

## Good to know

- `delta` is a fraction: `0.124` renders "+12.4%". It's green when it goes up and red when it goes down.
- Set `invertDelta` when a drop is good news, such as churn, latency or cost. A negative delta then turns green.
- `value` is a `ReactNode`, so format it yourself (`formatCurrency(48200)`) or pass a `Skeleton` while it loads.
- The card has no fixed size. Size the chart inside it with a height class such as `h-40` on `ChartContainer`.
- It has no chart logic, so it works for any content: charts, tables or a [Chart Skeleton](/charts/foundation/chart-skeleton).

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `ReactNode` | — | Card title |
| `description` | `ReactNode` | — | Line under the title |
| `value` | `ReactNode` | — | Headline number, already formatted |
| `delta` | `number` | — | Change as a fraction, shown as a badge |
| `invertDelta` | `boolean` | `false` | Treat a negative delta as good |
| `actions` | `ReactNode` | — | Top-right slot, e.g. a range toggle |
| `footer` | `ReactNode` | — | Footer note under the chart |
| `children` | `ReactNode` | — | The chart |
| `className` | `string` | — | Classes for the card |

## Usage

```tsx
import { InteractiveLegend } from "@/components/charts/interactive-legend";
```

```tsx
const [hidden, setHidden] = useState<string[]>([]);
const toggle = (key: string) =>
  setHidden((h) => (h.includes(key) ? h.filter((k) => k !== key) : [...h, key]));

<ChartLegend content={<InteractiveLegend config={config} onToggle={toggle} />} />
<Line dataKey="desktop" hide={hidden.includes("desktop")} />
```

## Anatomy

```tsx
<ChartLegend
  content={
    <InteractiveLegend   {/* row of toggle buttons */}
      config             {/* labels + icons */}
      onToggle           {/* click → show/hide */}
      onHighlight        {/* hover/focus → emphasise */}
    />
  }
/>
```

## Good to know

- You own the state. Keep the hidden keys in `useState` and pass `hide={hidden.includes(key)}` to each `Area`, `Bar` or `Line`.
- Hidden series stay in the legend, shown faded and struck through, so they can be turned back on. Recharts marks them `inactive`, and the legend reads that.
- `onHighlight` gets the hovered or focused key and `null` on leave. Use it to lower `fillOpacity` or `strokeOpacity` on the other series.
- Each item is a `<button>` with `aria-pressed`, so it works with the keyboard and screen readers announce whether the series is on.
- Pass the chart's `config` for labels and icons. Without it, items show the series key.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `config` | `ChartConfig` | — | Series labels and icons; pass the chart's config |
| `onToggle` | `(key: string) => void` | — | Called when an item is clicked |
| `onHighlight` | `(key: string \| null) => void` | — | Called on hover/focus, `null` on leave |
| `className` | `string` | — | Classes for the legend row |

`payload` and `verticalAlign` are filled in by Recharts. Set the position with `verticalAlign` on `ChartLegend`.

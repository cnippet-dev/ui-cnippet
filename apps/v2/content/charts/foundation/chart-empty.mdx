## Usage

```tsx
import { ChartEmpty } from "@/components/charts/chart-empty";
```

```tsx
{data.length === 0 ? (
  <ChartEmpty
    title="No payouts in this range"
    action={<Button onClick={widenRange}>Show last 90 days</Button>}
    className="aspect-auto h-48"
  />
) : (
  <ChartContainer config={config} className="h-48 w-full">…</ChartContainer>
)}
```

## Anatomy

```tsx
<ChartEmpty      {/* Empty */}
  icon           {/* EmptyMedia */}
  title          {/* EmptyTitle */}
  description    {/* EmptyDescription */}
  action         {/* EmptyContent */}
/>
```

## Good to know

- Match the chart's height so the card doesn't resize between states. It's `aspect-video` by default; add `aspect-auto` with a height class to override.
- Say why it's empty and what to do next: widen the range, clear a filter or send a test event.
- `icon` defaults to a bar-chart icon. Pass any icon to fit the context.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `title` | `ReactNode` | `"No data"` | Main message |
| `description` | `ReactNode` | `"There's nothing to show for this range yet."` | Supporting text |
| `icon` | `ReactNode` | bar-chart icon | Icon above the title |
| `action` | `ReactNode` | — | A button or link below the text |
| `className` | `string` | — | Sizing classes |

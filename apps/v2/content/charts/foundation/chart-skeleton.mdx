## Usage

```tsx
import { ChartSkeleton } from "@/components/charts/chart-skeleton";
```

```tsx
{loading ? (
  <ChartSkeleton variant="area" className="aspect-auto h-48" />
) : (
  <ChartContainer config={config} className="h-48 w-full">…</ChartContainer>
)}
```

## Good to know

- Give it the same height as the chart it stands in for, so nothing jumps when the data arrives. It's `aspect-video` by default; add `aspect-auto` with a height class to override.
- `variant` is `"bar"`, `"line"`, `"area"` or `"donut"`. Pick the shape of the chart that will replace it.
- It has `role="status"` and announces "Loading chart" to screen readers.
- The shimmer stops when the user has turned on reduced motion.
- The bar heights are fixed, so the server and client render the same thing.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"bar" \| "line" \| "area" \| "donut"` | `"bar"` | Shape of the placeholder |
| `className` | `string` | — | Sizing classes |

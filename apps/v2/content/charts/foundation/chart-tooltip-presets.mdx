## Usage

```tsx
import {
  ChartTooltipComparison,
  ChartTooltipList,
  ChartTooltipTotal,
} from "@/components/charts/chart-tooltip-presets";
```

```tsx
<ChartTooltip
  content={<ChartTooltipTotal config={config} valueFormatter={formatCurrency} />}
/>
```

## Anatomy

```tsx
<ChartTooltip content={<ChartTooltipTotal />} />      {/* every series + a "Total" row */}
<ChartTooltip content={<ChartTooltipList />} />       {/* series sorted highest first */}
<ChartTooltip content={<ChartTooltipComparison />} /> {/* value, previous value and % change */}
```

## Good to know

- Pass them to `ChartTooltip`'s `content`, like `ChartTooltipContent`. Recharts fills in `active`, `payload` and `label`.
- Pass the same `config` you give `ChartContainer` so rows show your series labels. Without it, rows fall back to the series key.
- `valueFormatter` defaults to `formatCompact` ("1.2K"). Use `formatCurrency`, `formatPercent` or your own function for units.
- `ChartTooltipComparison` needs `previous`, which maps each series to the data field holding last period's value, e.g. `{ revenue: "lastYear" }`. Series not in `previous` are left out of the tooltip.
- Set `invertDelta` on the comparison when a drop is good news, such as latency or cost.
- Non-numeric and `null` values are skipped, so gaps in your data don't break the tooltip.

## Props

All three presets take these props.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `config` | `ChartConfig` | — | Series labels; pass the chart's config |
| `valueFormatter` | `(value: number) => string` | `formatCompact` | Formats each value |
| `labelFormatter` | `(label: string \| number) => ReactNode` | — | Formats the heading (the x value) |
| `hideLabel` | `boolean` | `false` | Hide the heading |
| `className` | `string` | — | Classes for the tooltip box |

Preset-specific props:

| Preset | Prop | Type | Default | Description |
|------|------|------|---------|-------------|
| `ChartTooltipTotal` | `totalLabel` | `ReactNode` | `"Total"` | Label of the total row |
| `ChartTooltipList` | `limit` | `number` | — | Show only the top N series |
| `ChartTooltipComparison` | `previous` | `Record<string, string>` | — | Series key → previous-value field |
| `ChartTooltipComparison` | `invertDelta` | `boolean` | `false` | Treat a negative change as good |

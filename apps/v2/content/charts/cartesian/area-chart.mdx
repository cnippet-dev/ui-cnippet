## Usage

```tsx
import { AreaChart } from "@/components/charts/area-chart";
```

```tsx
const data = [
  { month: "Jan", desktop: 18640, mobile: 12210 },
  { month: "Feb", desktop: 21300, mobile: 14880 },
];

<AreaChart
  data={data}
  index="month"
  categories={["desktop", "mobile"]}
  className="h-64"
/>
```

## Good to know

- `index` is the field on the x-axis; `categories` are the fields to plot. Both are type-checked against `data`.
- Colours and labels come from `categories` automatically (`--chart-1`, `--chart-2`, …). Pass `config` to rename a series or pick its colour.
- `type="stacked"` piles series on top of each other and the tooltip adds a total. `type="percent"` stacks them to 100% and the y-axis shows percentages, while the tooltip keeps the real values.
- Size it with a height class such as `h-64`. It fills the width of its parent.
- `loading` shows an area-shaped skeleton; empty `data` shows a [Chart Empty](/charts/foundation/chart-empty) state, or your own `emptyState`.
- Pass Recharts elements such as `<ReferenceLine />` as children to draw on top of the chart.
- Animations turn off when the user has reduced motion on.

## Props

Takes all the [common chart props](/docs/chart-components/foundation#common-props), plus:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `type` | `"default" \| "stacked" \| "percent"` | `"default"` | How series combine |
| `curve` | `"linear" \| "monotone" \| "step"` | `"monotone"` | Line shape between points |
| `fill` | `"gradient" \| "solid" \| "none"` | `"gradient"` | Area fill under each line |
| `connectNulls` | `boolean` | `false` | Bridge `null` values instead of leaving a gap |

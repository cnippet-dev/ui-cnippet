## Usage

```tsx
import { CandlestickChart } from "@/components/charts/candlestick-chart";
```

```tsx
<CandlestickChart
  data={data} // [{ date, open, high, low, close }]
  index="date"
  valueFormatter={formatCurrency}
  className="h-64"
/>
```

## Good to know

- Fields default to `open`, `high`, `low` and `close`. Pass the `open` / `high` / `low` / `close` props if your data uses other names.
- A candle is `upColor` (`var(--success)`) when it closes at or above its open, otherwise `downColor` (`var(--destructive)`). The tooltip lists all four prices, so colour isn't the only signal.
- `volume` adds muted bars along the bottom quarter of the plot on their own hidden scale.
- The y-axis is fitted to the lowest low and highest high with round ticks, not started at zero.
- Add indicators as children: a moving average is a plain `<Line dataKey="ma7" />` on the price axis.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `T[]` | — | One row per period |
| `index` | `keyof T` | — | Date / period field |
| `open` / `high` / `low` / `close` | `keyof T` | `"open"` … | Price fields |
| `volume` | `keyof T` | — | Adds volume bars |
| `upColor` | `string` | `"var(--success)"` | Rising candle colour |
| `downColor` | `string` | `"var(--destructive)"` | Falling candle colour |
| `valueFormatter` | `(value: number) => string` | `formatCompact` | Formats prices |
| `volumeFormatter` | `(value: number) => string` | `formatCompact` | Formats volume in the tooltip |
| `indexFormatter` | `(value: string) => string` | — | Formats x values |
| `showXAxis` / `showYAxis` / `showGrid` / `showTooltip` | `boolean` | `true` | Toggle chart parts |
| `yAxisWidth` | `number` | `48` | Width of the y-axis in px |
| `loading` | `boolean` | `false` | Show a skeleton |
| `emptyState` | `ReactNode` | `<ChartEmpty />` | Shown when `data` is empty |
| `className` | `string` | — | Sizing, e.g. `"h-64"` |
| `aria-label` | `string` | — | Accessible name |
| `children` | `ReactNode` | — | Extra Recharts elements, e.g. a `<Line>` |
| `syncId` | `string` | — | Share a cursor with other charts |

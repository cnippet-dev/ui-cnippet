## Usage

```tsx
import { LineChart } from "@/components/charts/line-chart";
```

```tsx
<LineChart
  data={data}
  index="time"
  categories={["p50", "p90", "p99"]}
  valueFormatter={(value) => `${value} ms`}
  className="h-64"
/>
```

## Good to know

- `dashedCategories` draws those series dashed. Use it for forecasts, targets or last period.
- For a forecast that continues the actuals, repeat the last actual value in the forecast field on the same row so the two lines join (see the forecast example).
- `null` values leave a gap. Set `connectNulls` to draw straight across them.
- `showDots` marks every point; without it, a dot appears only on hover.
- Give `yAxisWidth` more room when tick labels carry units, e.g. `64` for "700 ms".

## Props

Takes all the [common chart props](/docs/chart-components/foundation#common-props), plus:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `curve` | `"linear" \| "monotone" \| "step"` | `"monotone"` | Line shape between points |
| `showDots` | `boolean` | `false` | Show a dot on every point |
| `dashedCategories` | `string[]` | `[]` | Series drawn dashed |
| `connectNulls` | `boolean` | `false` | Bridge `null` values instead of leaving a gap |

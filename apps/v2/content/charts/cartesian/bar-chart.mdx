## Usage

```tsx

```

```tsx
<BarChart
  data={data}
  index="month"
  categories={["revenue"]}
  valueFormatter={formatCurrency}
  className="h-64"
/>
```

## Good to know

- `layout="horizontal"` (default) draws columns. `layout="vertical"` draws bars that grow to the right, which fits long labels such as page paths. Widen the label column with `yAxisWidth`.
- With more than one category, bars sit side by side. `type="stacked"` stacks them and `type="percent"` stacks them to 100%.
- `showValues` prints each value at the end of its bar. It's ignored for stacked types, where the tooltip shows the values.
- Only the outer end of a bar is rounded; in a stack, only the top segment.
- `onValueClick` receives `{ index, category, value }` for the clicked bar, e.g. to filter a table or drill down.
- Negative values grow below zero. Add `<ReferenceLine y={0} />` as a child to mark the axis.

## Props

Takes all the [common chart props](/docs/chart-components/foundation#common-props), plus:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `layout` | `"horizontal" \| "vertical"` | `"horizontal"` | Columns, or bars growing right |
| `type` | `"default" \| "stacked" \| "percent"` | `"default"` | How series combine |
| `showValues` | `boolean` | `false` | Label each bar with its value |
| `radius` | `number` | `4` | Corner radius of the bar end, in px |
| `barCategoryGap` | `string \| number` | — | Gap between groups, e.g. `"20%"` |
| `onValueClick` | `(payload: { index, category, value }) => void` | — | Called when a bar is clicked |

## Usage

```tsx
import { ComboChart } from "@/components/charts/combo-chart";
```

```tsx
<ComboChart
  data={data}
  index="month"
  barCategories={["revenue"]}
  lineCategories={["growth"]}
  dualAxis
  valueFormatter={formatCurrency}
  lineValueFormatter={(value) => formatPercent(value)}
  className="h-64"
/>
```

## Good to know

- Use `barCategories` and `lineCategories` instead of `categories`. Colours are assigned across both lists in order.
- Without `dualAxis`, bars and lines share the left axis, so use it only when both are in the same unit.
- With `dualAxis`, lines get their own right-hand axis. `lineValueFormatter` formats that axis and the line values in the tooltip.
- `stacked` stacks the bar series; lines are never stacked.
- Children such as `<ReferenceLine />` attach to the left axis by default.

## Props

Takes all the [common chart props](/docs/chart-components/foundation#common-props) except `categories`, plus:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `barCategories` | `string[]` | — | Series drawn as bars |
| `lineCategories` | `string[]` | — | Series drawn as lines |
| `dualAxis` | `boolean` | `false` | Put the lines on a right-hand axis |
| `lineValueFormatter` | `(value: number) => string` | `valueFormatter` | Formats line values and the right axis |
| `stacked` | `boolean` | `false` | Stack the bar series |
| `curve` | `"linear" \| "monotone" \| "step"` | `"monotone"` | Line shape between points |

## Usage

```tsx
import { SparkArea } from "@/components/charts/spark-area";
```

```tsx
<SparkArea data={data} index="day" categories={["revenue"]} />
```

## Good to know

- It's `h-10 w-32` by default. Pass `className` to resize, e.g. `"h-14 w-full"` inside a card.
- The y-axis fits the data's min and max, so small changes still show as a shape.
- `colorByTrend` colours a single series green when it ends higher than it starts and red when lower. Add `invertTrend` for metrics where up is bad, such as errors or cost.
- There's no tooltip or axes; put the current value next to the sparkline as text.
- It has `role="img"` and an accessible name built from the props. In a list or table, pass `aria-label` per row (e.g. "Acme weekly users trend").

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `T[]` | — | Rows to plot |
| `index` | `keyof T` | — | Field for the x position |
| `categories` | `(keyof T)[]` | — | Numeric fields to plot |
| `config` | `ChartConfig` | built from `categories` | Labels or colours per series |
| `colorByTrend` | `boolean` | `false` | Green when rising, red when falling |
| `invertTrend` | `boolean` | `false` | Flip the trend colours |
| `type` | `"default" \| "stacked"` | `"default"` | Stack multiple series |
| `curve` | `"linear" \| "monotone" \| "step"` | `"monotone"` | Line shape |
| `className` | `string` | — | Sizing classes |
| `aria-label` | `string` | built from the props | Accessible name |

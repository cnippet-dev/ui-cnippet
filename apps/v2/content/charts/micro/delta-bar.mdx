## Usage

```tsx
import { DeltaBar } from "@/components/charts/delta-bar";
```

```tsx
<DeltaBar value={0.124} />
```

## Good to know

- `value` is a fraction from `-1` to `1`, like `delta` on [Chart Card](/charts/foundation/chart-card): `0.124` fills 12.4% of the right half. Larger values are clamped.
- Growth is green and decline is red. Set `invertDelta` when a drop is good news, such as cost or tickets.
- The default accessible name is the signed percentage. Pass `aria-label` to add context ("Billing NPS up 7 points").
- Show the number next to the bar as text too; the bar alone is hard to read precisely.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `number` | — | Change as a fraction, `-1` to `1` |
| `invertDelta` | `boolean` | `false` | Treat a negative change as good |
| `className` | `string` | — | Classes for the track |
| `aria-label` | `string` | signed percentage | Accessible name |

## Usage

```tsx
import { ProgressCircle } from "@/components/charts/progress-circle";
```

```tsx
<ProgressCircle value={72} aria-label="Profile completion">
  72%
</ProgressCircle>
```

## Good to know

- `value` runs from 0 to `max` (default 100) and is clamped to that range.
- It has `role="progressbar"` with `aria-valuenow`, `aria-valuemin` and `aria-valuemax`. Always pass `aria-label`.
- `children` render in the centre; keep them short, like a percentage or an icon.
- `color` takes any CSS colour. Pick it from the value for thresholds (see the quota example).
- `size` is the diameter in px; scale `strokeWidth` with it.
- The arc animates when `value` changes, unless the user has reduced motion on.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `number` | — | Current progress |
| `max` | `number` | `100` | Value for a full ring |
| `size` | `number` | `64` | Diameter in px |
| `strokeWidth` | `number` | `6` | Ring thickness in px |
| `color` | `string` | `var(--chart-1)` | CSS colour of the arc |
| `children` | `ReactNode` | — | Centre content |
| `className` | `string` | — | Classes for the wrapper |
| `aria-label` | `string` | — | Accessible name |

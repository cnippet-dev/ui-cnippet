## Usage

```tsx
import { Tracker } from "@/components/charts/tracker";
```

```tsx
<Tracker
  aria-label="API status, last 90 days"
  data={[
    { color: "var(--success)", tooltip: "Oct 24 — Operational" },
    { color: "var(--warning)", tooltip: "Oct 25 — Degraded" },
  ]}
/>
```

## Good to know

- Each block takes a CSS `color` and a `tooltip`. Map your own statuses to colours, e.g. `var(--success)`, `var(--warning)`, `var(--destructive)`. Blocks without a colour use `--muted`.
- `tooltip` is also each block's accessible name, so write it as a full sentence ("Oct 12 — Operational").
- The row is a single tab stop. Arrow keys move between blocks, Home and End jump to the ends, and the focused block shows its tooltip.
- `aria-label` is required: it names the whole row for screen readers.
- Blocks stretch to fill the width; the gap shrinks on small screens. Change the height with `className`, e.g. `h-6`.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `{ color?, tooltip, key? }[]` | — | One entry per block, oldest first |
| `aria-label` | `string` | — | Name of the row (required) |
| `className` | `string` | — | Sizing classes |

## Usage

```tsx
import { SparkLine } from "@/components/charts/spark-line";
```

```tsx
<SparkLine data={prices} index="day" categories={["price"]} colorByTrend showLastDot />
```

## Good to know

- `showLastDot` marks the latest value, which helps in tickers and status lists.
- `colorByTrend` and `invertTrend` work as in [Spark Area](/charts/micro/spark-area): green when it ends higher, red when lower, flipped with `invertTrend`.
- For a fixed colour (e.g. amber for a degraded service), set it in `config` instead.
- It's `h-10 w-32` by default; `className="h-8 flex-1"` lets it fill a row.
- Pass `aria-label` per row so each line has a meaningful name.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `T[]` | — | Rows to plot |
| `index` | `keyof T` | — | Field for the x position |
| `categories` | `(keyof T)[]` | — | Numeric fields to plot |
| `config` | `ChartConfig` | built from `categories` | Labels or colours per series |
| `colorByTrend` | `boolean` | `false` | Green when rising, red when falling |
| `invertTrend` | `boolean` | `false` | Flip the trend colours |
| `showLastDot` | `boolean` | `false` | Dot on the last point |
| `curve` | `"linear" \| "monotone" \| "step"` | `"monotone"` | Line shape |
| `className` | `string` | — | Sizing classes |
| `aria-label` | `string` | built from the props | Accessible name |

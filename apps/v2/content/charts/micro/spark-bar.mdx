## Usage

```tsx
import { SparkBar } from "@/components/charts/spark-bar";
```

```tsx
<SparkBar data={data} index="day" categories={["commits"]} />
```

## Good to know

- `colorBySign` paints positive bars green and negative bars red. For a win/loss record, use `1` and `-1`.
- `type="stacked"` stacks several series, e.g. web and app orders.
- There's no zero line or axis; keep the record short (a few weeks) so each bar stays readable.
- Give a summary in `aria-label`, e.g. "9 wins, 6 losses in the last 15 games".

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `T[]` | — | Rows to plot |
| `index` | `keyof T` | — | Field for the x position |
| `categories` | `(keyof T)[]` | — | Numeric fields to plot |
| `config` | `ChartConfig` | built from `categories` | Labels or colours per series |
| `colorBySign` | `boolean` | `false` | Green for positive, red for negative |
| `type` | `"default" \| "stacked"` | `"default"` | Stack multiple series |
| `className` | `string` | — | Sizing classes |
| `aria-label` | `string` | built from the props | Accessible name |

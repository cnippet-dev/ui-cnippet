## Usage

```tsx
import { BulletChart } from "@/components/charts/bullet-chart";
```

```tsx
<BulletChart value={98400} target={120000} ranges={[84000, 120000, 150000]} />
```

## Anatomy

```tsx
<BulletChart
  ranges   {/* grey bands behind, darkest first */}
  value    {/* the coloured bar */}
  target   {/* the vertical marker */}
/>
```

## Good to know

- `ranges` are the upper bounds of the bands, ascending, e.g. poor / ok / good. The first band is darkest.
- `max` sets the end of the scale. Without it, the scale ends at the largest of `value`, `target` and `ranges`.
- `color` sets the bar colour. Use it for status, e.g. red when an SLA is breached.
- The default accessible name reads "98.4K of 150K, target 120K" using `valueFormatter`. Pass `aria-label` for more context.
- Pair it with the numbers as text: the bar shows how close, the text shows exactly.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `number` | — | Current value, drawn as the bar |
| `target` | `number` | — | Goal, drawn as a marker |
| `max` | `number` | largest input | End of the scale |
| `ranges` | `number[]` | `[]` | Upper bounds of the background bands |
| `color` | `string` | `var(--chart-1)` | CSS colour of the bar |
| `valueFormatter` | `(value: number) => string` | `formatCompact` | Formats the accessible name |
| `className` | `string` | — | Classes for the wrapper |
| `aria-label` | `string` | built from the props | Accessible name |

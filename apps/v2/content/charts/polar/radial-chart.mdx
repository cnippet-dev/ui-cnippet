## Usage

```tsx
import { RadialChart } from "@/components/charts/radial-chart";
```

```tsx
<RadialChart
  data={[
    { goal: "Move", progress: 81 },
    { goal: "Exercise", progress: 64 },
  ]}
  index="goal"
  category="progress"
  max={100}
  className="h-60"
/>
```

## Good to know

- Each row is one ring: `index` names it and `category` fills it. The first row is the innermost ring.
- Set `max` to the value of a full ring (e.g. `100` for percentages). Without it, the largest value fills a full ring.
- Rings start at 12 o'clock and run clockwise. For a half ring, use `startAngle={180}` and `endAngle={0}`.
- Ring colours are keyed by ring name in `config`, like the [Donut Chart](/charts/polar/donut-chart).
- For a single progress value outside a chart card, [Progress Circle](/charts/micro/progress-circle) is lighter.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `T[]` | — | One row per ring |
| `index` | `keyof T` | — | Field that names each ring |
| `category` | `keyof T` | — | Numeric field that fills each ring |
| `max` | `number` | largest value | Value of a full ring |
| `config` | `ChartConfig` | built from ring names | Labels or colours per ring |
| `valueFormatter` | `(value: number) => string` | `formatCompact` | Formats tooltip values |
| `startAngle` / `endAngle` | `number` | `90` / `-270` | Arc in degrees |
| `showBackground` | `boolean` | `true` | Show the empty track |
| `centerValue` / `centerLabel` | `string` | — | Centre text |
| `showLegend` / `showTooltip` | `boolean` | `true` | Toggle legend and tooltip |
| `loading` | `boolean` | `false` | Show a skeleton |
| `emptyState` | `ReactNode` | `<ChartEmpty />` | Shown when `data` is empty |
| `className` | `string` | — | Sizing classes |
| `aria-label` | `string` | built from the props | Accessible name |

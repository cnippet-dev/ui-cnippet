## Usage

```tsx
import { RadarChart } from "@/components/charts/radar-chart";
```

```tsx
<RadarChart data={data} index="aspect" categories={["air", "pro"]} className="h-64" />
```

## Good to know

- Each row is one axis (`index`) and each category is one shape.
- Uses the [common chart props](/docs/chart-components/foundation#common-props), except the x/y-axis ones.
- `filled={false}` draws outlines only, which reads better with three or more series.
- `gridType="circle"` swaps the polygon grid for circles; `showDots` marks each value.
- Keep axes on the same scale (e.g. all out of 10) so the shape is meaningful.

## Props

Takes the [common chart props](/docs/chart-components/foundation#common-props) except `showXAxis`, `showYAxis` and `yAxisWidth`, plus:

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `gridType` | `"polygon" \| "circle"` | `"polygon"` | Shape of the grid |
| `filled` | `boolean` | `true` | Fill each shape |
| `showDots` | `boolean` | `false` | Dot on each value |

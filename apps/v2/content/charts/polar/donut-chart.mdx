## Usage

```tsx
import { DonutChart } from "@/components/charts/donut-chart";
```

```tsx
<DonutChart
  data={[
    { channel: "Organic", visitors: 18420 },
    { channel: "Direct", visitors: 9310 },
  ]}
  index="channel"
  category="visitors"
  centerValue="27.7K"
  centerLabel="Visitors"
  className="h-60"
/>
```

## Good to know

- `index` names each slice and `category` sizes it. Each row is one slice.
- Slices get `--chart-1` … `--chart-5` in order. To recolour one, key `config` by the slice name, e.g. `{ Free: { color: "var(--muted)" } }`. Names with spaces or symbols become dashes (`"Customer success"` → `"Customer-success"`).
- `centerValue` and `centerLabel` print in the hole. Pass the total yourself, e.g. `formatCompact(sumBy(data, ["visitors"]))`.
- `showLabels` prints each slice's share next to it, which helps when there's no legend.
- `legendLayout="side"` lists the legend beside the chart; use it in wider cards.
- The hovered slice grows a little. Keyboard users can move between slices with the arrow keys.
- Keep it to about six slices. Beyond that, group the smallest into "Other".

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `T[]` | — | One row per slice |
| `index` | `keyof T` | — | Field that names each slice |
| `category` | `keyof T` | — | Numeric field that sizes each slice |
| `config` | `ChartConfig` | built from slice names | Labels or colours per slice |
| `valueFormatter` | `(value: number) => string` | `formatCompact` | Formats tooltip values |
| `variant` | `"donut" \| "pie"` | `"donut"` | With or without a hole |
| `centerValue` | `string` | — | Big text in the hole |
| `centerLabel` | `string` | — | Small text under the value |
| `showLabels` | `boolean` | `false` | Print each slice's share |
| `showLegend` | `boolean` | `true` | Toggle the legend |
| `legendLayout` | `"bottom" \| "side"` | `"bottom"` | Legend placement |
| `showTooltip` | `boolean` | `true` | Toggle the tooltip |
| `loading` | `boolean` | `false` | Show a donut skeleton |
| `emptyState` | `ReactNode` | `<ChartEmpty />` | Shown when `data` is empty |
| `className` | `string` | — | Sizing classes, e.g. `"h-60"` |
| `aria-label` | `string` | built from the props | Accessible name |

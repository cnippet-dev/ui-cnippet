## Usage

```tsx
import { PolarAreaChart } from "@/components/charts/polar-area-chart";
```

```tsx
<PolarAreaChart data={data} index="day" category="workouts" color="var(--chart-1)" className="h-64" />
```

## Good to know

- Every slice gets the same angle, so it suits cyclic data: weekdays, hours, compass directions.
- A slice's **area** grows with its value (its length grows with the square root), so a value twice as big looks twice as big.
- Pass `color` for one colour across all slices; the legend then hides by default since the labels are in the tooltip. Without `color`, each slice gets its own colour and a legend.
- The first slice is centred on 12 o'clock and the rest follow clockwise in data order, so a compass rose starting with "N" points the right way.
- Each slice's name is printed at its outer edge, so the chart reads without a legend.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `T[]` | — | One row per slice |
| `index` | `keyof T` | — | Field that names each slice |
| `category` | `keyof T` | — | Numeric field for the slice size |
| `config` | `ChartConfig` | built from slice names | Labels or colours per slice |
| `color` | `string` | — | One colour for every slice |
| `valueFormatter` | `(value: number) => string` | `formatCompact` | Formats tooltip values |
| `showLegend` | `boolean` | `true` without `color` | Toggle the legend |
| `showTooltip` | `boolean` | `true` | Toggle the tooltip |
| `loading` | `boolean` | `false` | Show a skeleton |
| `emptyState` | `ReactNode` | `<ChartEmpty />` | Shown when `data` is empty |
| `className` | `string` | — | Sizing classes |
| `aria-label` | `string` | built from the props | Accessible name |

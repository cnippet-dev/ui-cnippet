## Usage

```tsx
import { SunburstChart } from "@/components/charts/sunburst-chart";
```

```tsx
<SunburstChart
  data={[
    {
      name: "Americas",
      children: [
        { name: "United States", value: 412000 },
        { name: "Canada", value: 68000 },
      ],
    },
    { name: "Other", value: 52000 },
  ]}
  className="h-64"
/>
```

## Good to know

- Data is a tree two levels deep. A node with `children` gets the sum of its children; a node without them needs its own `value`.
- Children take their parent's colour, alternating between two tints so neighbours stay apart.
- The legend lists the top level only; the tooltip names any slice you hover.
- For more than two levels or many small slices, a bar chart is easier to read.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `{ name, value?, children? }[]` | — | Top-level nodes with optional children |
| `config` | `ChartConfig` | built from top-level names | Labels or colours per top-level node |
| `valueFormatter` | `(value: number) => string` | `formatCompact` | Formats tooltip values |
| `showLegend` / `showTooltip` | `boolean` | `true` | Toggle legend and tooltip |
| `loading` | `boolean` | `false` | Show a skeleton |
| `emptyState` | `ReactNode` | `<ChartEmpty />` | Shown when `data` is empty |
| `className` | `string` | — | Sizing classes, e.g. `"h-64"` |
| `aria-label` | `string` | built from the names | Accessible name |

## Usage

```tsx
import { PieChart } from "@/components/charts/pie-chart";
```

```tsx
<PieChart data={data} index="browser" category="share" className="h-60" />
```

## Good to know

- `PieChart` is `DonutChart` with `variant="pie"`, so it takes the same props except the centre text. Installing it also installs Donut Chart.
- Everything on the [Donut Chart](/charts/polar/donut-chart) page applies: slice colours keyed by name, `showLabels`, side legend and keyboard navigation.
- A donut with a total in the centre usually reads better. Use a pie when the shares themselves are the story.

## Props

All [Donut Chart props](/charts/polar/donut-chart#props) except `variant`, `centerValue` and `centerLabel`.

## Good to know

- `text` is drawn on one line, so keep it short: a word or a short phrase.
- It reads the font, size, weight and letter spacing from the surrounding text, so style it with normal Tailwind classes.
- `colors` accepts any CSS color, including `var(--token)` values, which are read from the page. The default is `var(--chart-1)` to `var(--chart-5)`, so it follows your theme.
- Screen readers read the text once; the canvas is hidden from them.
- The drawing loop pauses when the text is off screen or the tab is hidden, and the canvas resolution is capped at 2× device pixel ratio.
- When the user has turned on reduced motion, it draws one still frame.
- It is SSR-safe: nothing touches `window` until it mounts.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `text` | `string` | — | Text to draw |
| `as` | `React.ElementType` | `"span"` | Element rendered as the wrapper |
| `colors` | `string[]` | `chart tokens` | Line colors; CSS variables are resolved |
| `lineCount` | `number` | `12` | Number of flowing lines |
| `lineWidth` | `number` | — | Line thickness in px; by default slightly more than each line's band, so the text reads solid |
| `speed` | `number` | `1` | Animation speed multiplier |
| `className` | `string` | — | Classes for the wrapper, e.g. font size |

## Anatomy

```tsx
<TextFlippingBoard text={["ROW ONE", "ROW TWO"]} rows={2} cols={10} /> {/* grid of flap cells, one per character */}
```

## Good to know

- Pass a string to wrap it word by word into `cols`, or an array to set each row yourself. Text is upper-cased and padded with spaces.
- Change `text` to flip to a new message. Each cell steps through `charset` in order, so a longer distance means more flips. Put characters in the order they usually change; for a countdown use `"9876543210:"`.
- Characters that are not in `charset` are shown directly without flipping.
- Size it with a font-size class: cells are sized in `em`.
- Screen readers read the full text once; the grid is hidden from them.
- When the user has turned on reduced motion, every cell shows the new character straight away.
- On the server every cell renders blank, so the board flips in on load.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `text` | `string \| string[]` | — | Text to show; an array sets one row per item |
| `rows` | `number` | `1` | Number of rows |
| `cols` | `number` | `12` | Characters per row |
| `flipDuration` | `number` | `0.08` | Seconds per flip |
| `charset` | `string` | `DEFAULT_CHARSET` | Order the flaps cycle through (space, A–Z, 0–9, `:.-/!?`) |
| `className` | `string` | — | Classes for the wrapper, e.g. font size |
| `cellClassName` | `string` | — | Classes for each cell |

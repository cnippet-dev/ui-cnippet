## Usage

```tsx
import { ScrollSnapSections } from "@/components/motion/scroll-snap-sections";
```

```tsx
<ScrollSnapSections
  sections={[
    { id: "intro", label: "Intro", content: <Intro /> },
    { id: "pricing", label: "Pricing", content: <Pricing /> },
  ]}
/>
```

## Anatomy

```tsx
<ScrollSnapSections sections={…} /> {/* scroll container of <section>s + dot <nav> */}
```

## Good to know

- It is its own scroll container and fills the viewport height by default; set the size with `className`.
- Each section is a labelled `<section>`. The dots are buttons named after each section's `label`, and the current one has `aria-current`.
- Use `direction="horizontal"` for slides.
- When the user has turned on reduced motion, sections appear without the entrance animation and the dots jump instead of smooth-scrolling.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `sections` | `{ id, label, content, className? }[]` | — | Sections to render |
| `direction` | `"vertical" \| "horizontal"` | `"vertical"` | Scroll and snap direction |
| `showDots` | `boolean` | `true` | Shows the dot navigation |
| `className` | `string` | — | Classes for the outer box, e.g. its height |

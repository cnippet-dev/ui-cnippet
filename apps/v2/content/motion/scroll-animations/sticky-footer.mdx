## Usage

```tsx
import { StickyFooter } from "@/components/motion/sticky-footer";
```

```tsx
<StickyFooter height={320}>
  <div className="size-full bg-foreground text-background">…</div>
</StickyFooter>
```

## Anatomy

```tsx
<StickyFooter height={…}>{/* footer content */}</StickyFooter> {/* clipped <footer> > sticky content */}
```

## Good to know

- Put it last on the page. It needs a fixed `height`: a number in px, or any CSS length.
- It is pure CSS (`position: sticky` and `clip-path`), so it needs no scroll listeners or extra packages, and it works inside any scroll container.
- Give the footer content its own background.
- Reduced motion makes no difference because nothing animates: the page simply scrolls off the footer.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | — | Footer content |
| `height` | `number \| string` | `320` | Footer height; numbers are px |
| `contentClassName` | `string` | — | Classes for the sticky content |
| `...props` | `ComponentProps<"footer">` | — | Passed to the `<footer>` |

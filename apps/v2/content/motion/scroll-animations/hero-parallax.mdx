## Usage

```tsx
import { HeroParallax } from "@/components/motion/hero-parallax";
```

```tsx
<HeroParallax products={products}>
  <h1>Selected work</h1>
</HeroParallax>
```

## Anatomy

```tsx
<HeroParallax products={[{ title, link, thumbnail }]}>{/* header */}</HeroParallax>
```

## Good to know

- Products are split evenly across `rows`. Each card is a link; `title` is the image `alt` text and the hover caption.
- Rows alternate direction. `distance` is the horizontal travel in px, and `rowSpeeds` multiplies it per row, so different speeds read as different depths.
- Card captions also appear on keyboard focus.
- `containerRef`: pass a ref to a scrollable element when the section scrolls inside its own box instead of the window, as the previews here do. That element must be positioned (for example the `relative` class), or the scroll progress is measured against the wrong ancestor.
- When the user has turned on reduced motion, the cards and rows stay still and the hover lift is off.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `products` | `{ title, link, thumbnail }[]` | — | Cards to show |
| `rows` | `number` | `3` | Number of rows |
| `distance` | `number` | `600` | Horizontal travel per row in px |
| `rowSpeeds` | `number[]` | — | Speed multiplier per row |
| `children` | `ReactNode` | — | Header content above the rows |
| `containerRef` | `RefObject<HTMLElement \| null>` | — | Scrollable ancestor to track instead of the window |
| `className` | `string` | — | Classes for the wrapper |
| `cardClassName` | `string` | — | Classes for each card |

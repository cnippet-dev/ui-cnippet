## Anatomy

```tsx
<ContainerScroll header={…}>{/* card content */}</ContainerScroll>
```

## Good to know

- The animation runs from when the component enters the bottom of the screen until it is centred.
- `rotate` and `scale` are `[start, end]` pairs; the end values are the resting state.
- Change the card shape with `cardClassName`, for example a narrow, rounded card for a phone.
- `containerRef`: pass a ref to a scrollable element when the section scrolls inside its own box instead of the window, as the previews here do. That element must be positioned (for example the `relative` class), or the scroll progress is measured against the wrong ancestor.
- When the user has turned on reduced motion, the card sits at its end rotation and scale and the header does not move.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | — | Card content |
| `header` | `ReactNode` | — | Content above the card |
| `rotate` | `[number, number]` | `[20, 0]` | rotateX in degrees, start to end |
| `scale` | `[number, number]` | `[1.05, 1]` | Card scale, start to end |
| `containerRef` | `RefObject<HTMLElement \| null>` | — | Scrollable ancestor to track instead of the window |
| `className` | `string` | — | Classes for the wrapper |
| `cardClassName` | `string` | — | Classes for the card |

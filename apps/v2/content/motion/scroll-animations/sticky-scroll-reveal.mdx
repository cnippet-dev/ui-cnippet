## Usage

```tsx
import { StickyScrollReveal } from "@/components/motion/sticky-scroll-reveal";
```

```tsx
<StickyScrollReveal
  items={[
    { title: "Instant deploys", description: "…", content: <img src="…" alt="" /> },
    { title: "Analytics", description: "…", content: <Chart /> },
  ]}
/>
```

## Anatomy

```tsx
<StickyScrollReveal items={items} /> {/* text column + sticky content panel */}
```

## Good to know

- The step crossing the middle of the screen is active. Its text is fully opaque and its `content` shows in the sticky panel.
- On screens narrower than `md` there is no sticky panel; each step shows its content under its text instead.
- `containerRef`: pass a ref to a scrollable element when the section scrolls inside its own box instead of the window, as the previews here do. That element must be positioned (for example the `relative` class), or the scroll progress is measured against the wrong ancestor.
- The active step gets `aria-current="step"`.
- When the user has turned on reduced motion, the opacity and content changes happen instantly.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `items` | `{ title, description, content }[]` | — | Steps; `content` is any React node |
| `containerRef` | `RefObject<HTMLElement \| null>` | — | Scrollable ancestor to track instead of the window |
| `className` | `string` | — | Classes for the grid |
| `itemClassName` | `string` | — | Classes for each text step |
| `contentClassName` | `string` | — | Classes for the content panel |

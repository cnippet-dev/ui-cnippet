## Good to know

- It renders a sticky `<header>`, so place it at the top of the scrolling area, or at the bottom with `side="bottom"`.
- `threshold` is how many px you must scroll in one direction before it toggles. It is always shown near the top.
- `hideOn="up"` flips the behaviour, which suits toolbars that should stay while reading.
- Tabbing into it brings it back, so keyboard users never lose it.
- `containerRef`: pass a ref to a scrollable element when the section scrolls inside its own box instead of the window, as the previews here do. That element must be positioned (for example the `relative` class), or the scroll progress is measured against the wrong ancestor.
- When the user has turned on reduced motion, it still hides and shows, but instantly, without sliding.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `children` | `ReactNode` | — | Header content |
| `threshold` | `number` | `12` | Px scrolled before it toggles |
| `hideOn` | `"down" \| "up"` | `"down"` | Scroll direction that hides it |
| `side` | `"top" \| "bottom"` | `"top"` | Edge it sticks to and slides out of |
| `containerRef` | `RefObject<HTMLElement \| null>` | — | Scrollable ancestor to track instead of the window |
| `...props` | `HTMLMotionProps<"header">` | — | Passed to the `<header>` |

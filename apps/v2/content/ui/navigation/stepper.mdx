## Usage

```tsx
import {
  Stepper,
  StepperDescription,
  StepperIndicator,
  StepperItem,
  StepperSeparator,
  StepperTitle,
  StepperTrigger,
} from "@/components/ui/stepper"
```

```tsx
const [step, setStep] = useState(1)

<Stepper value={step} onValueChange={setStep}>
  {["Cart", "Shipping", "Payment"].map((title, i) => (
    <StepperItem key={title} step={i + 1}>
      <StepperTrigger>
        <StepperIndicator />
        <StepperTitle>{title}</StepperTitle>
      </StepperTrigger>
      <StepperSeparator />
    </StepperItem>
  ))}
</Stepper>
```

## Anatomy

```tsx
<Stepper>                      {/* <ol>; holds the active step */}
  <StepperItem step={1}>       {/* <li>; data-state is completed, active or inactive */}
    <StepperTrigger>           {/* button that makes this step active */}
      <StepperIndicator />     {/* number, or a check when completed */}
      <StepperTitle />
      <StepperDescription />
    </StepperTrigger>
    <StepperSeparator />       {/* line to the next step; hidden on the last one */}
  </StepperItem>
</Stepper>
```

## Good to know

- Steps start at 1. Every step before `value` shows as completed, `value` is active, and later steps are upcoming. Use `completed` on a `StepperItem` to mark a step done out of order.
- The active item gets `aria-current="step"`, so screen readers announce where the user is.
- `StepperTrigger` is optional. Leave it out (as in the compact example) when users shouldn't click between steps, and use `disabled` on an item to block steps they haven't reached yet.
- The stepper only shows progress. Render each step's content yourself, based on the same `value`.
- Style by state with `group-data-[state=completed]/step:` and friends, since every part sits inside a `group/step` item.

## API Reference

### Stepper

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `number` | — | Controlled active step |
| `defaultValue` | `number` | `1` | Initial active step when uncontrolled |
| `onValueChange` | `(step: number) => void` | — | Called when a trigger is clicked |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Layout direction |

### StepperItem

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `step` | `number` | — | This step's number, starting at 1 |
| `completed` | `boolean` | — | Show as completed regardless of `value` |
| `disabled` | `boolean` | `false` | Disables this step's trigger |

### StepperIndicator

Shows the step number, or a check when completed. Pass children to show something else, such as an icon.

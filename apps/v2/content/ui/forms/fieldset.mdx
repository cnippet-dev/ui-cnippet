## Usage

```tsx
import { Fieldset, FieldsetLegend } from "@/components/ui/fieldset"
```

```tsx
<Fieldset>
  <FieldsetLegend>Fieldset legend</FieldsetLegend>
</Fieldset>
```

## Anatomy

```tsx
<Fieldset> {/* <fieldset> · data-slot="fieldset" */}
  <FieldsetLegend>Shipping address</FieldsetLegend> {/* names the group · data-slot="fieldset-legend" */}
  <Field>…</Field>
  <Field>…</Field>
</Fieldset>
```

## Good to know

- Use a `Fieldset` to group related controls, such as a set of radio buttons or several fields for one address. Screen readers announce the legend before each control inside.
- `FieldsetLegend` renders a `<div>` that labels the fieldset through `aria-labelledby`, not a native `<legend>`. It can go anywhere inside the `Fieldset`.
- `disabled` on `Fieldset` disables every control inside it.
- `Fieldset` has a built-in `max-w-64` width limit. Override it with `className="max-w-none"` or another width.

## API Reference

### Fieldset

Styled `<fieldset>` wrapper. Setting `disabled` disables all interactive elements inside at the browser level — no JavaScript needed.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `disabled` | `boolean` | `false` | Disables all interactive elements inside the fieldset |

### FieldsetLegend

The `<legend>` element that names the group for screen readers. Announced before each input inside the fieldset.

## Usage

```tsx
import {
  FileUpload,
  FileUploadDropzone,
  FileUploadList,
} from "@/components/ui/file-upload"
```

```tsx
<FileUpload accept="image/*" maxSize={2 * 1024 * 1024} multiple>
  <FileUploadDropzone />
  <FileUploadList />
</FileUpload>
```

## Anatomy

```tsx
<FileUpload>                          {/* state, validation and the hidden <input type="file"> */}
  <FileUploadDropzone />              {/* drop target; click or Enter/Space opens the picker */}
  <FileUploadTrigger />               {/* a Button that opens the picker */}
  <FileUploadList>                    {/* renders nothing until a file is added */}
    {(file) => (
      <FileUploadItem file={file}>
        <FileUploadItemPreview file={file} />   {/* image thumbnail or file icon */}
        <FileUploadItemMetadata file={file} />  {/* name and size, or an error */}
        <FileUploadItemDelete file={file} />    {/* remove button */}
      </FileUploadItem>
    )}
  </FileUploadList>
</FileUpload>
```

## Good to know

- `FileUpload` only collects files. Uploading them is up to you: read the list from `onValueChange`, or submit the hidden input with a form by passing `name`.
- Files that fail `accept`, `maxSize` or `maxFiles` are never added. Each one calls `onFileReject(file, reason)` with `"type"`, `"size"` or `"count"`, so you can show your own message.
- Without `multiple`, a new file replaces the current one.
- `accept` uses the native format: MIME types (`image/png`), wildcards (`image/*`) and extensions (`.pdf`). It's checked for dropped files too, since the browser only filters the picker.
- `useFileUpload()` gives any child the `files`, `addFiles`, `removeFile`, `clearFiles` and `openFilePicker` helpers, for custom layouts like an avatar or a gallery.
- Don't put a `FileUploadTrigger` inside a `FileUploadDropzone`. Both open the picker, so a click would open it twice.

## API Reference

### FileUpload

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `File[]` | — | Controlled files |
| `defaultValue` | `File[]` | `[]` | Initial files when uncontrolled |
| `onValueChange` | `(files: File[]) => void` | — | Called when files are added or removed |
| `onFileReject` | `(file: File, reason: "type" \| "size" \| "count") => void` | — | Called for each file that fails validation |
| `accept` | `string` | — | Allowed types, as for `<input accept>` |
| `maxSize` | `number` | — | Largest allowed file, in bytes |
| `maxFiles` | `number` | — | Most files allowed when `multiple` |
| `multiple` | `boolean` | `false` | Allow more than one file |
| `disabled` | `boolean` | `false` | Disables the dropzone, trigger and input |
| `name` | `string` | — | Name for the hidden input, for form submission |

### FileUploadDropzone

A focusable drop target. Gets `data-dragging` while files are over it and `data-disabled` when disabled. Renders an upload icon and "Drop files here or browse" when it has no children.

### FileUploadTrigger

A [Button](/ui/actions/button) (`variant="outline"` by default) that opens the file picker. Takes all Button props.

### FileUploadList

| Prop | Type | Description |
|------|------|-------------|
| `children` | `(file: File) => ReactNode` | Renders each file. Defaults to `<FileUploadItem file={file} />` |

### FileUploadItem

| Prop | Type | Description |
|------|------|-------------|
| `file` | `File` | The file to show |
| `progress` | `number` | 0–100. Shows a progress bar while set |
| `error` | `string` | Shown instead of the size; sets `data-invalid` |

Renders a preview, name, size and remove button unless you pass your own children.

### Helpers

`isFileAccepted(file, accept)` and `formatFileSize(bytes)` are exported too.

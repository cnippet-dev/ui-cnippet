## Usage

```tsx
import { ToggleGroup, ToggleGroupItem } from "@/components/ui/toggle-group"
```

```tsx
<ToggleGroup>
  <ToggleGroupItem value="bold">Bold</ToggleGroupItem>
  <ToggleGroupItem value="italic">Italic</ToggleGroupItem>
  <ToggleGroupItem value="underline">Underline</ToggleGroupItem>
</ToggleGroup>
```

## Anatomy

```tsx
<ToggleGroup variant="outline"> {/* root, owns the pressed values · data-slot="toggle-group" */}
  <ToggleGroupItem value="bold">Bold</ToggleGroupItem> {/* <button> · data-slot="toggle" */}
  <ToggleGroupSeparator /> {/* optional divider · data-slot="separator" */}
  <ToggleGroupItem value="italic">Italic</ToggleGroupItem>
</ToggleGroup>
```

## Good to know

- Built on Base UI, not Radix. Use `multiple` to allow several pressed items. There is no `type="single"` or `type="multiple"` prop.
- `value`, `defaultValue` and `onValueChange` always use an array, even when only one item can be pressed: `defaultValue={["bold"]}`.
- Give every item a unique `value`. The group uses it to track which items are pressed.
- Set `variant` and `size` on `ToggleGroup`. Items always use the group's values.
- Use `ToggleGroupItem` for the items, not `Toggle`, so they pick up the group's styling.
- `orientation="vertical"` stacks the items and switches arrow-key navigation to up and down.

## API Reference

### ToggleGroup

Root container that provides shared `variant` and `size` context to all child `ToggleGroupItem` elements.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"default" \| "outline"` | `"default"` | Visual style applied to all items |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` | Size applied to all items |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Layout direction of the group |
| `value` | `string[]` | — | Controlled array of pressed item values |
| `defaultValue` | `string[]` | `[]` | Initial pressed values for uncontrolled usage |
| `onValueChange` | `(value: string[]) => void` | — | Callback when the selection changes |
| `multiple` | `boolean` | `false` | Whether multiple items can be active simultaneously |

### ToggleGroupItem

Individual toggle inside a `ToggleGroup`. Always uses the group's `variant` and `size`.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `value` | `string` | — | Unique identifier for this item (required) |
| `disabled` | `boolean` | `false` | Prevents interaction for this item only |

### ToggleGroupSeparator

Visual divider between toggle items. Best used with the `outline` variant.

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `orientation` | `"horizontal" \| "vertical"` | `"vertical"` | Direction of the separator line |

## Usage

Wrap your layout in `SidebarProvider`, then put the `Sidebar` and your page (`SidebarInset`) side by side.

```tsx
import {
  Sidebar,
  SidebarContent,
  SidebarGroup,
  SidebarGroupLabel,
  SidebarInset,
  SidebarMenu,
  SidebarMenuButton,
  SidebarMenuItem,
  SidebarProvider,
  SidebarTrigger,
} from "@/components/ui/sidebar"
```

```tsx
export default function AppLayout({ children }: { children: React.ReactNode }) {
  return (
    <SidebarProvider>
      <Sidebar collapsible="icon">
        <SidebarContent>
          <SidebarGroup>
            <SidebarGroupLabel>Workspace</SidebarGroupLabel>
            <SidebarMenu>
              <SidebarMenuItem>
                <SidebarMenuButton isActive tooltip="Inbox">
                  <InboxIcon />
                  <span>Inbox</span>
                </SidebarMenuButton>
              </SidebarMenuItem>
            </SidebarMenu>
          </SidebarGroup>
        </SidebarContent>
      </Sidebar>
      <SidebarInset>
        <header>
          <SidebarTrigger />
        </header>
        {children}
      </SidebarInset>
    </SidebarProvider>
  )
}
```

## Anatomy

```tsx
<SidebarProvider>                 {/* open state, keyboard shortcut, mobile detection */}
  <Sidebar>
    <SidebarHeader />
    <SidebarContent>              {/* scrolls */}
      <SidebarGroup>
        <SidebarGroupLabel />
        <SidebarGroupAction />    {/* e.g. a "+" next to the label */}
        <SidebarGroupContent>
          <SidebarMenu>
            <SidebarMenuItem>
              <SidebarMenuButton />
              <SidebarMenuAction />
              <SidebarMenuBadge />
              <SidebarMenuSub>
                <SidebarMenuSubItem>
                  <SidebarMenuSubButton />
                </SidebarMenuSubItem>
              </SidebarMenuSub>
            </SidebarMenuItem>
          </SidebarMenu>
        </SidebarGroupContent>
      </SidebarGroup>
    </SidebarContent>
    <SidebarFooter />
    <SidebarRail />               {/* thin edge you can click to toggle */}
  </Sidebar>
  <SidebarInset>                  {/* your page */}
    <SidebarTrigger />
  </SidebarInset>
</SidebarProvider>
```

## Good to know

- Cmd+B (Ctrl+B on Windows and Linux) toggles the sidebar.
- Below the `md` breakpoint the sidebar opens as a [Sheet](/ui/overlays/sheet) from `SidebarTrigger` instead of sitting beside the page.
- The open state is saved in a `sidebar_state` cookie for a week. Read it on the server and pass it as `defaultOpen` so the first render matches what the user left it at.
- With `collapsible="icon"`, the collapsed sidebar shows only icons. Give each `SidebarMenuButton` a `tooltip` so its label still appears on hover.
- The sidebar is `position: fixed` to the viewport. The examples here sit in a box with `transform-gpu`, which makes that box the containing block so the demo stays inside it. You don't need that in a real app shell.
- `useSidebar()` returns `state`, `open`, `setOpen`, `openMobile`, `setOpenMobile`, `isMobile` and `toggleSidebar` for custom controls.

## API Reference

### SidebarProvider

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `defaultOpen` | `boolean` | `true` | Initial open state when uncontrolled |
| `open` | `boolean` | — | Controlled open state |
| `onOpenChange` | `(open: boolean) => void` | — | Called when the sidebar opens or closes |

Set `--sidebar-width` and `--sidebar-width-icon` in `style` to change the widths (defaults `16rem` and `3rem`).

### Sidebar

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `side` | `"left" \| "right"` | `"left"` | Which edge it sits on |
| `variant` | `"sidebar" \| "floating" \| "inset"` | `"sidebar"` | Flush panel, floating card, or panel with the page inset beside it |
| `collapsible` | `"offcanvas" \| "icon" \| "none"` | `"offcanvas"` | Slide fully away, shrink to icons, or never collapse |

### SidebarMenuButton

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `isActive` | `boolean` | `false` | Marks the current page |
| `tooltip` | `string \| TooltipPopup props` | — | Shown on hover while collapsed to icons |
| `size` | `"sm" \| "default" \| "lg"` | `"default"` | Height |
| `variant` | `"default" \| "outline"` | `"default"` | Plain or outlined |
| `render` | `ReactElement` | — | Render as another element, such as a link |

### SidebarMenuSubButton

Renders an `<a>` by default. Takes `isActive`, `size` (`"sm" \| "md"`) and `render`.

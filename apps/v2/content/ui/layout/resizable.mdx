## Usage

```tsx
import {
  ResizableHandle,
  ResizablePanel,
  ResizablePanelGroup,
} from "@/components/ui/resizable"
```

```tsx
<ResizablePanelGroup className="h-64 rounded-xl border">
  <ResizablePanel defaultSize="30%" minSize="20%">Sidebar</ResizablePanel>
  <ResizableHandle withHandle />
  <ResizablePanel>Content</ResizablePanel>
</ResizablePanelGroup>
```

## Good to know

- Built on [react-resizable-panels](https://github.com/bvaughn/react-resizable-panels) v4. Every prop it takes passes through.
- Sizes: a **string is a percentage** (`"30%"` or `"30"`) and a **number is pixels** (`200`). Other units such as `"16rem"` work too.
- The group needs a height. Give it one with `className`, or let it fill a parent that has one.
- Stack panels with `orientation="vertical"` on the group, and nest a group inside a panel for editor-style layouts.
- Handles are focusable: the arrow keys resize, Home and End jump to the limits, and double-clicking a handle resets its panels to their default sizes.
- Add `collapsible` (and optionally `collapsedSize`) to a panel to let it snap shut when dragged past `minSize`.
- To remember the layout, pass `useDefaultLayout({ id, storage: localStorage })` to the group, and give each panel an `id`, as in the mail example.

## API Reference

### ResizablePanelGroup

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` | Direction panels are laid out |
| `defaultLayout` | `Layout` | — | Saved sizes, e.g. from `useDefaultLayout` |
| `onLayoutChanged` | `(layout: Layout) => void` | — | Called when a resize finishes |

### ResizablePanel

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `defaultSize` | `number \| string` | auto | Starting size |
| `minSize` / `maxSize` | `number \| string` | — | Size limits |
| `collapsible` | `boolean` | `false` | Snaps to `collapsedSize` past `minSize` |
| `collapsedSize` | `number \| string` | `0%` | Size when collapsed |
| `id` | `string` | — | Needed for saved layouts |

### ResizableHandle

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `withHandle` | `boolean` | `false` | Shows a grip so the handle reads as draggable |

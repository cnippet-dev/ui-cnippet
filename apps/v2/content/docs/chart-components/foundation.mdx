Foundation covers the Recharts primitive, the shared helpers and states every chart component builds on, and the colour tokens that keep charts in step with your theme.

- **[Chart](/charts/foundation/chart)** — Themeable charts built on Recharts, mapped to your CSS variables automatically.
- **[Chart Utils](/charts/foundation/chart-utils)** — Number and date formatters plus a ChartConfig builder.
- **[Chart Card](/charts/foundation/chart-card)** — Card frame with title, headline value, delta badge, actions and footer.
- **[Chart Tooltip Presets](/charts/foundation/chart-tooltip-presets)** — Tooltip layouts for totals, sorted lists and period comparisons.
- **[Interactive Legend](/charts/foundation/interactive-legend)** — Legend that toggles series and highlights them on hover.
- **[Chart Skeleton](/charts/foundation/chart-skeleton)** — Loading placeholder shaped like a bar, line, area or donut chart.
- **[Chart Empty](/charts/foundation/chart-empty)** — Empty state sized for a chart, with a message and action.

## Common props

The data-driven charts ([Area](/charts/cartesian/area-chart), [Bar](/charts/cartesian/bar-chart), [Line](/charts/cartesian/line-chart), [Combo](/charts/cartesian/combo-chart)) share these props, so you learn them once.

```tsx
<AreaChart
  data={data}                       // rows
  index="month"                     // field on the x-axis
  categories={["desktop", "mobile"]} // fields to plot
  valueFormatter={formatCompact}
  className="h-64"
/>
```

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `data` | `T[]` | — | Rows to plot |
| `index` | `keyof T` | — | Field on the x-axis, e.g. `"month"` |
| `categories` | `(keyof T)[]` | — | Numeric fields to plot as series |
| `config` | `ChartConfig` | built from `categories` | Labels, icons or colours per series |
| `valueFormatter` | `(value: number) => string` | `formatCompact` | Formats the y-axis and tooltip values |
| `indexFormatter` | `(value: string) => string` | — | Formats x-axis ticks and the tooltip heading |
| `showXAxis` / `showYAxis` | `boolean` | `true` | Toggle each axis |
| `showGrid` | `boolean` | `true` | Toggle grid lines |
| `showLegend` | `boolean` | more than one series | Toggle the legend |
| `showTooltip` | `boolean` | `true` | Toggle the tooltip |
| `legendPosition` | `"top" \| "bottom"` | `"bottom"` | Legend placement |
| `yAxisWidth` | `number` | `48` | Width of the y-axis labels; raise it for units |
| `loading` | `boolean` | `false` | Show a [Chart Skeleton](/charts/foundation/chart-skeleton) |
| `emptyState` | `ReactNode` | `<ChartEmpty />` | Shown when `data` is empty |
| `className` | `string` | — | Sizing classes, e.g. `"h-64"` |
| `aria-label` | `string` | built from the props | Accessible name of the chart |
| `children` | `ReactNode` | — | Extra Recharts elements, e.g. `<ReferenceLine />` |
| `syncId` | `string` | — | Charts with the same id share a cursor and tooltip position |

`data`, `index` and `categories` are type-checked against each other: a typo in a field name is a type error. The type is `BaseChartProps` in [Chart Utils](/charts/foundation/chart-utils).

## Colours & theming

Chart colours come from the `--chart-1` … `--chart-5` CSS variables, with separate light and dark values. Point a series at a token through `ChartConfig`, then reference it as `var(--color-<key>)`.

```tsx
const chartConfig = {
  desktop: { color: "var(--chart-1)", label: "Desktop" },
  mobile: { color: "var(--chart-2)", label: "Mobile" },
} satisfies ChartConfig;
```

[`buildChartConfig`](/charts/foundation/chart-utils) builds the same object from a list of keys, assigning the tokens in order.

The tokens are OKLCH values, so use them as `var(--chart-1)`. Wrapping them as `hsl(var(--chart-1))` produces an invalid colour and the series renders blank.

---
title: Text Animations
description: Components that animate text — on entrance, hover, or as values change.
---

Text animation components add motion to typography, from character-level reveals to live-updating numbers, built on [Motion](https://motion.dev/).

- **[Text Reveal](/motion/text-animations/text-reveal)** — Reveals text progressively as it enters view.
- **[Text Scramble](/motion/text-animations/text-scramble)** — Scrambles characters before settling into the final text.
- **[Scramble Hover](/motion/text-animations/scramble-hover)** — Scrambles text on hover interaction.
- **[Typewriter](/motion/text-animations/typewriter)** — Types text out character by character.
- **[Text Loop](/motion/text-animations/text-loop)** — Cycles through a list of text strings.
- **[Text Morph](/motion/text-animations/text-morph)** — Morphs smoothly from one string to another.
- **[Text Roll](/motion/text-animations/text-roll)** — Rolls characters vertically into place.
- **[Flip Words](/motion/text-animations/flip-words)** — Flips between words with a 3D rotation effect.
- **[Counting Number](/motion/text-animations/counting-number)** — Animates a number counting up or down to a target value.
- **[Text Rotate](/motion/text-animations/text-rotate)** — Rotates through a list of phrases with animated transitions.
- **[Vertical Cut Reveal](/motion/text-animations/vertical-cut-reveal)** — Reveals text with a vertical cut/wipe transition.
- **[Letter Swap Hover](/motion/text-animations/letter-swap-hover)** — Swaps letters on hover for a playful effect.
- **[Text Shimmer](/motion/text-animations/text-shimmer)** — Applies a shimmering light sweep across text.
- **[Text Shimmer Wave](/motion/text-animations/text-shimmer-wave)** — A wave-based variant of the shimmer effect.
- **[Text Gradient](/motion/text-animations/text-gradient)** — Applies an animated gradient fill to text.
- **[Text Highlight](/motion/text-animations/text-highlight)** — Animates a highlight sweeping across text.
- **[Sliding Number](/motion/text-animations/sliding-number)** — Slides digits in and out when a number value changes.
- **[Animated Number](/motion/text-animations/animated-number)** — Smoothly transitions a number between values.
- **[Spinning Text](/motion/text-animations/spinning-text)** — Text arranged in a circle that spins continuously.
- **[Breathing Text](/motion/text-animations/breathing-text)** — Text that softly pulses in scale or opacity.
- **[Splitting Text](/motion/text-animations/splitting-text)** — Animates text split into characters, words, or lines.
- **[Rolling Text](/motion/text-animations/rolling-text)** — Rolls text characters in on entrance.
- **[Rotating Text](/motion/text-animations/rotating-text)** — Rotates between a list of text values.
- **[Morphing Text](/motion/text-animations/morphing-text)** — Morphs shape and form between two text strings.
- **[Colorful Text](/motion/text-animations/colorful-text)** — Cycles text through a sequence of colors.
- **[Encrypted Text](/motion/text-animations/encrypted-text)** — Displays text as if it's being decrypted in real time.
- **[Text Generate Effect](/motion/text-animations/text-generate-effect)** — Generates text word by word, like an AI response.
- **[Letter 3D Swap](/motion/text-animations/letter-3d-swap)** — Swaps letters using a 3D flip transition.
- **[Random Letter Swap](/motion/text-animations/random-letter-swap)** — Swaps letters in a random order on trigger.
- **[Scroll Swap Text](/motion/text-animations/scroll-swap-text)** — Swaps text content in response to scroll position.
- **[Variable Font Hover](/motion/text-animations/variable-font-hover)** — Animates variable font axes on hover.
- **[Variable Font Cursor Proximity](/motion/text-animations/variable-font-cursor-proximity)** — Animates variable font axes based on cursor distance.
- **[Text Cursor Proximity](/motion/text-animations/text-cursor-proximity)** — Animates text properties based on cursor proximity.
- **[Text Along Path](/motion/text-animations/text-along-path)** — Animates text moving along an SVG path.

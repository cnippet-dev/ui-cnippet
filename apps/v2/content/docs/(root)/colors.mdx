cnippet ui colors are CSS variables built on the Tailwind CSS palette. Each token has a light value in `:root` and a dark value in `.dark`. Tailwind turns each one into utilities, so `--primary` becomes `bg-primary`, `text-primary`, `border-primary` and so on.

Each swatch shows the light value on the left and the dark value on the right. The copy button copies the CSS variable, for example `var(--primary)`.

## Using tokens

Use the Tailwind utilities in your components. Pair every surface token with its `-foreground` token so text stays readable in both themes:

```tsx
<div className="rounded-lg border bg-card p-4 text-card-foreground">
  <p className="text-muted-foreground">Last updated 2 minutes ago</p>
  <span className="text-success-foreground">Deployed</span>
</div>
```

Opacity modifiers work on every token, for example `bg-primary/10` or `border-destructive/32`.

In plain CSS or inline styles, use the variable:

```css
.chart-tooltip {
  background: var(--popover);
  color: var(--popover-foreground);
  border: 1px solid var(--border);
}
```

## Status colors

`info`, `success` and `warning` are extra tokens that shadcn/ui doesn't have. Each has two values:

- **The base token** (`--success`) is a strong color for fills, borders, icons and dots.
- **The `-foreground` token** (`--success-foreground`) is a darker shade in light mode and a lighter one in dark mode, for text on the page background or on a light tint such as `bg-success/8`.

`destructive` works the same way. Alert, Badge and Toast use these tokens for their `info`, `success`, `warning` and `error` variants.

## Changing colors

To change a color, edit its value in both `:root` and `.dark` in your global stylesheet. Anything you don't override keeps the default. See [Theming](/docs/theming) for custom palettes and [Dark Mode](/docs/dark-mode) for switching themes.

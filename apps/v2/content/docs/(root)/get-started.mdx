This guide walks you through adding **cnippet ui** components to your React project. You'll be up and running in less than 5 minutes.

## Prerequisites

Make sure your project meets these requirements:

- **React 18+** (Next.js, Vite, React Router, TanStack Start, Astro — all work)
- **Tailwind CSS v4** – [Install Tailwind](https://tailwindcss.com/docs/installation)
- **Node.js** (a current LTS release) – for the CLI

Starting a new project, or not sure your setup is ready? Follow the guide for your framework:

| Framework | Guide |
|-----------|-------|
| Next.js | [Install with Next.js](/docs/installation/next) |
| Vite | [Install with Vite](/docs/installation/vite) |
| React Router | [Install with React Router](/docs/installation/react-router) |
| TanStack Start | [Install with TanStack Start](/docs/installation/tanstack-start) |
| Astro | [Install with Astro](/docs/installation/astro) |
| Anything else | [Manual Installation](/docs/installation/manual) |

## Two ways to add components

You can add components **automatically with the CLI** (recommended) or **manually**.

### Option 1: CLI (fast & automated)

The CLI creates component files, installs dependencies, and sets up CSS variables for you. If your project doesn't have a `components.json` yet, run `npx shadcn@latest init` first.

#### Add a single component

```bash
npx shadcn@latest add @cnippet/button
```

This creates `components/ui/button.tsx` and installs any required packages (e.g., `@base-ui/react`).

#### Add multiple components

```bash
npx shadcn@latest add @cnippet/button @cnippet/card @cnippet/dialog
```

#### Add all UI components at once

```bash
npx shadcn@latest add @cnippet/ui
```

Adds all 55+ core components – perfect for starting a new project.

#### Add the color tokens (recommended)

```bash
npx shadcn@latest add @cnippet/colors-neutral
```

This replaces the default colors in your global CSS with the cnippet ui tokens, including the `info`, `success` and `warning` colors. See [Colors](/docs/colors) for every token.

#### Set up everything in one command

```bash
npx shadcn@latest init @cnippet/style
```

Sets up `components.json`, the color tokens, fonts, base styles and every component.

**What the CLI does for you:**

- Creates `components/ui/` folder (if missing)
- Adds the component file with correct imports
- Installs npm dependencies
- Updates your CSS with required variables (when using color tokens)

See the [CLI reference](/docs/cli) for every command and option, and [components.json](/docs/components-json) for the config file.

### Option 2: Manual copy (full control)

Prefer to copy-paste manually? Here's how:

1. Set up the dependencies, the `cn` helper and the CSS tokens from [Manual Installation](/docs/installation/manual).
2. Browse the [Components](/explore) page and pick one (e.g., Button).
3. In the **Installation** section, choose **Manual** and copy the code.
4. Create a new file in your project, e.g., `components/ui/button.tsx`, and paste the code.
5. Install the dependencies listed on the component's page.
6. Import and use the component:

```tsx
import { Button } from "@/components/ui/button"

export default function MyComponent() {
  return <Button variant="outline">Click me</Button>
}
```

## Styling and dark mode

Components are styled with Tailwind CSS classes and a set of CSS variables for colors and radius. Every token has a light and a dark value, so dark mode works as soon as a `dark` class is on `<html>`.

- [Colors](/docs/colors) lists every token with its light and dark value.
- [Theming](/docs/theming) shows how to change colors and radius.
- [Dark Mode](/docs/dark-mode) sets up theme switching for your framework.

## Verify your setup

After adding a component, test it on a page:

```tsx
import { Button } from "@/components/ui/button"

export default function TestPage() {
  return (
    <div className="p-8 space-x-4">
      <Button>Default</Button>
      <Button variant="destructive">Delete</Button>
      <Button variant="outline">Outline</Button>
    </div>
  )
}
```

If you see styled buttons, everything works. If something is wrong, see the [FAQ](/docs/faq) for fixes to common problems, like a missing import alias or unstyled components.

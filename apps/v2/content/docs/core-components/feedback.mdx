---
title: Feedback
description: Components for communicating status, progress, and system messages to the user.
---

Feedback components tell the user what's happening — a status, a warning, a loading state, or a shortcut.

- **[Alert](/ui/feedback/alert)** — Displays a callout for user attention, such as an error or warning.
- **[Badge](/ui/feedback/badge)** — A small count or status descriptor for UI elements.
- **[Kbd](/ui/feedback/kbd)** — Represents keyboard input or a keyboard shortcut.
- **[Progress](/ui/feedback/progress)** — Displays an indicator showing the completion progress of a task.
- **[Skeleton](/ui/feedback/skeleton)** — Used to show a placeholder while content is loading.
- **[Spinner](/ui/feedback/spinner)** — An indicator showing that a task is in progress.
- **[Toast](/ui/feedback/toast)** — A succinct message that shows up temporarily to give the user feedback.

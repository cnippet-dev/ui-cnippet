---
title: Forms
description: Inputs, fields, and controls for collecting and validating user input.
---

Form components handle user input — text, selection, and numeric entry — with built-in labeling, validation, and grouping primitives.

- **[Checkbox](/ui/forms/checkbox)** — A control that allows the user to toggle between checked and not checked.
- **[Checkbox Group](/ui/forms/checkbox-group)** — Groups multiple checkboxes so their selection state can be managed together.
- **[Field](/ui/forms/field)** — Wraps a form control with a label, description, and validation message.
- **[Fieldset](/ui/forms/fieldset)** — Groups related form fields together under a common legend.
- **[Form](/ui/forms/form)** — A wrapper that manages form-wide validation state.
- **[Input](/ui/forms/input)** — A field that lets users enter and edit text.
- **[Input Group](/ui/forms/input-group)** — Composes an input with adornments like icons, buttons, or text.
- **[Label](/ui/forms/label)** — Renders an accessible label associated with a form control.
- **[Meter](/ui/forms/meter)** — Displays a scalar value within a known range, like disk usage.
- **[Number Field](/ui/forms/number-field)** — An input restricted to numeric values, with increment/decrement controls.
- **[OTP Field](/ui/forms/otp-field)** — A segmented input for one-time passcodes and verification codes.
- **[Radio Group](/ui/forms/radio-group)** — A set of checkable buttons where only one can be checked at a time.
- **[Slider](/ui/forms/slider)** — Allows users to select a value or range from within a given range.
- **[Textarea](/ui/forms/textarea)** — A multi-line text input field.

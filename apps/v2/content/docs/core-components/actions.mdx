---
title: Actions
description: Buttons and controls users interact with to trigger an action or change a state.
---

Action components are the primary way users trigger commands, submit intent, or toggle a state. They're built on Base UI primitives and cover single-press buttons through multi-select toggle groups.

- **[Button](/ui/actions/button)** — A button, or a component that looks and behaves like one. The base for most clickable actions.
- **[Switch](/ui/actions/switch)** — A binary on/off control, typically used for settings.
- **[Toggle](/ui/actions/toggle)** — A two-state button that can be either on or off.
- **[Toggle Group](/ui/actions/toggle-group)** — A set of two-state buttons that can be grouped together, single or multi-select.
- **[Toolbar](/ui/actions/toolbar)** — A container for grouping a set of controls, such as buttons and toggles.

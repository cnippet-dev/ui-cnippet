---
title: Overlays
description: Components that render above the page — dialogs, menus, popovers, and tooltips.
---

Overlay components render on top of the page content, typically triggered by user interaction, and manage their own focus and dismissal behavior.

- **[Alert Dialog](/ui/overlays/alert-dialog)** — A modal dialog that interrupts the user to require confirmation.
- **[Command](/ui/overlays/command)** — A command palette for fast, keyboard-driven navigation and actions.
- **[Context Menu](/ui/overlays/context-menu)** — A menu triggered by right-click, displayed at the cursor position.
- **[Dialog](/ui/overlays/dialog)** — A window overlaid on the primary content, requiring user interaction.
- **[Drawer](/ui/overlays/drawer)** — A panel that slides in from an edge of the screen.
- **[Popover](/ui/overlays/popover)** — Displays rich content in a portal, anchored to a trigger.
- **[Sheet](/ui/overlays/sheet)** — An extension of the dialog component for displaying content that complements the main content.
- **[Tooltip](/ui/overlays/tooltip)** — A popup that displays information when hovering or focusing an element.

---
title: Data Display
description: Components for presenting structured content, collapsible sections, and empty states.
---

Data display components render and organize content — from tabular data to collapsible sections and charts.

- **[Accordion](/ui/data/accordion)** — A vertically stacked set of interactive headings that reveal a section of content.
- **[Chart](/ui/data/chart)** — Themeable charts built on Recharts, mapped to your CSS variables automatically.
- **[Collapsible](/ui/data/collapsible)** — An interactive component which expands or collapses a panel of content.
- **[Empty](/ui/data/empty)** — A placeholder for empty states, no results, or missing data.
- **[Table](/ui/data/table)** — A component for displaying tabular data in rows and columns.

---
title: Navigation
description: Components for moving between views, pages, and sections of content.
---

Navigation components help users find their way around — between pages, sections, and nested menus.

- **[Breadcrumb](/ui/navigation/breadcrumb)** — Displays the path to the current resource in a hierarchy.
- **[Menu](/ui/navigation/menu)** — Displays a list of actions or options a user can choose from.
- **[Pagination](/ui/navigation/pagination)** — Splits content across multiple pages with navigable controls.
- **[Tabs](/ui/navigation/tabs)** — A set of layered sections of content, one visible at a time.

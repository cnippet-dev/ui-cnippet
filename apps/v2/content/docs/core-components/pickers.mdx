---
title: Pickers
description: Components for selecting a value, date, or option from a set of choices.
---

Picker components let users choose a value from a list, calendar, or filtered search — often combining an input with an overlay.

- **[Autocomplete](/ui/pickers/autocomplete)** — A text input with a list of suggestions filtered as you type.
- **[Calendar](/ui/pickers/calendar)** — A date field component that allows users to select a single date.
- **[Combobox](/ui/pickers/combobox)** — Combines a text input with a searchable, selectable list.
- **[Date Picker](/ui/pickers/date-picker)** — An input paired with a calendar overlay for selecting a date.
- **[Select](/ui/pickers/select)** — Displays a list of options for the user to pick from, triggered by a button.

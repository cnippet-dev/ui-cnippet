The CLI does all of this for you. Follow these steps if you want to see every file that changes, or if you can't run the CLI in your project.

<Steps>

### Add Tailwind CSS

Components are styled with Tailwind CSS v4. Follow the [Tailwind CSS installation guide](https://tailwindcss.com/docs/installation) for your framework.

### Add dependencies

```bash
npm install @base-ui/react class-variance-authority clsx tailwind-merge lucide-react
```

```bash
npm install -D tw-animate-css
```

Some components need more packages (for example Calendar needs `react-day-picker`). Each component page lists them under **Installation → Manual**.

### Configure the import alias

Components import each other through `@/`. Add the alias to `tsconfig.json`:

```json title="tsconfig.json"
{
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./*"]
    }
  }
}
```

Use `["./src/*"]` if your code lives in `src/`. Vite also needs the alias in `vite.config.ts`. See the [Vite guide](/docs/installation/vite).

### Add the cn helper

Every component uses `cn` to merge class names.

```ts title="lib/utils.ts"
import { type ClassValue, clsx } from "clsx";
import { twMerge } from "tailwind-merge";

export function cn(...inputs: ClassValue[]): string {
  return twMerge(clsx(inputs));
}
```

Values like `--alpha(var(--color-black) / 8%)` are Tailwind CSS v4 functions. Tailwind compiles them, so they only work inside a stylesheet that Tailwind processes. [Colors](/docs/colors) shows every token with a swatch.

### Add fonts (optional)

The theme reads `--font-sans`, `--font-heading` and `--font-mono` and falls back to system fonts. cnippet ui uses Inter for text and Geist Mono for code. In Next.js:

```tsx title="app/layout.tsx"
import { Geist_Mono, Inter } from "next/font/google";

const sans = Inter({ subsets: ["latin"], variable: "--font-sans" });
const heading = Inter({ subsets: ["latin"], variable: "--font-heading" });
const mono = Geist_Mono({ subsets: ["latin"], variable: "--font-mono" });

export default function RootLayout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" className={`${sans.variable} ${heading.variable} ${mono.variable}`}>
      <body>{children}</body>
    </html>
  );
}
```

### Add components

Open a component page, for example [Button](/ui/actions/button), and choose **Manual** in the Installation section. Copy the source into `components/ui/button.tsx` and install the dependencies listed there.

```tsx
import { Button } from "@/components/ui/button";

export default function Page() {
  return <Button>Click me</Button>;
}
```

Some components import others (a Dialog uses Button, for example). The Manual tab lists these too. Add them the same way.

## Add a components.json (optional)

If you add a `components.json`, you can use the CLI later without running `init` again:

```json title="components.json"
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "new-york",
  "rsc": true,
  "tsx": true,
  "tailwind": {
    "config": "",
    "css": "app/globals.css",
    "baseColor": "neutral",
    "cssVariables": true
  },
  "iconLibrary": "lucide",
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils",
    "ui": "@/components/ui",
    "lib": "@/lib",
    "hooks": "@/hooks"
  }
}
```

Set `rsc` to `false` if you don't use React Server Components, and `tailwind.config` stays empty for Tailwind CSS v4. See [components.json](/docs/components-json) for every field.
